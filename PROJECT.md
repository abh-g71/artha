# ARTHA Project Constitution

## Project name
ARTHA

## Project purpose
ARTHA is an autonomous AI buyer and agentic commerce platform that turns natural-language shopping intent into a safe, explainable, bounded transaction workflow.

## Razorpay Buildathon track
01 — AI Growth & Agentic Commerce

## Core objective
Build an AI buyer agent that can understand user intent, discover merchant offerings, evaluate products against structured requirements, obtain appropriate authorization, and complete a bounded payment through Razorpay Test Mode while maintaining policy compliance, explainability, and a complete audit trail.

## Core architecture principle
AI proposes.
Policy decides.
User authorizes when required.
Backend executes.
Razorpay processes.
Webhook confirms.
Audit records.
Evaluation proves.

The LLM must never directly authorize financial transactions.

## Core capabilities
- Natural-language intent understanding
- Structured requirement extraction
- Merchant and product discovery
- Product filtering, comparison, and recommendation
- Policy-aware authorization flow
- Controlled user confirmation when required
- Merchant order creation and payment preparation
- Razorpay Test Mode payments
- Payment verification and webhook handling
- Failure-safe transaction behavior
- Audit trail for meaningful actions
- Evaluation dataset and measurement of safety and quality

## Non-goals
- Real-money transactions or production payment processing
- Backend, frontend, database, or AI implementation work beyond project planning and documentation
- Unauthorized LLM-driven financial decisions
- Redesigning the technology stack
- Adding unrelated features not described in the specification
- Deployment or production launch activities
- Any work beyond the approved Phase 0 documentation scope
